# Хранение артефактов

В этой секции рассматриваются методы хранения артефактов, используемых в процессах автоматизации и CI/CD. Обсуждаются инструменты и лучшие практики для эффективного управления артефактами.

## Введение в хранение артефактов

Эффективное управление артефактами в CI/CD (и в Jenkins в частности) критически важно для обеспечения воспроизводимости сборок, безопасности и экономии дискового пространства. Хранить всё внутри самого Jenkins — антипаттерн.

Основные практики работы с артефактами CI/CD делятся на несколько ключевых направлений:

- Централизованное хранение артефактов вне Jenkins;
- Версионирование артефактов;
- Политики хранения и очистки артефактов;
- Концепция продвижения артефактов (artifact promotion);
- Безопасность и сканирование;
- Интеграция и трассируемость.

## Инструменты и технологии для хранения артефактов

### JFrog Artifactory

JFrog Artifactory является одним из наиболее популярных инструментов для хранения артефактов. Он поддерживает различные типы репозиториев, включая Maven, npm, Docker и другие, обеспечивая централизованное управление артефактами и их версионирование.

### GitHub Packages

GitHub Packages предоставляет возможность хранения и управления артефактами непосредственно в экосистеме GitHub. Он поддерживает различные типы пакетов, включая npm, Maven, Docker и другие, что позволяет интегрировать управление артефактами с процессами CI/CD на GitHub.

### Nexus Repository

Nexus Repository является ещё одним популярным инструментом для хранения артефактов. Он поддерживает различные типы репозиториев, включая Maven, npm, Docker и другие, обеспечивая централизованное управление артефактами и их версионирование.

## Интеграция Jenkins и JFrog Artifactory

Для интеграции Jenkins с JFrog Artifactory необходимо установить соответствующий плагин в Jenkins и настроить подключение к серверу Artifactory. Это позволяет автоматически загружать артефакты в репозиторий Artifactory в процессе выполнения конвейеров CI/CD.

Основные шаги интеграции включают:

- Установка плагина JFrog Artifactory в Jenkins;
- Настройка подключения к серверу Artifactory;
- Конфигурация этапов конвейера для публикации артефактов в Artifactory;
- Управление версиями и зависимостями артефактов через Artifactory.
